## 先认识一下

大家好，我是 Fuhao574。这个网站的主人，也是它的前端、后端、测试、运维和唯一的运营——毕竟现在的访客大概率只有我自己，外加几位勤勤恳恳的搜索引擎爬虫。

**这个世界不缺大人** 是这个站的名字，也会一直挂在浏览器标签页上。它具体是什么意思，我说不太清楚，但每次看到都觉得挺自由的：

> 这个世界不缺按部就班的大人，缺的是还愿意从零开始学点东西的人。

## 为什么 2026 年了还要自己搭网站

先坦白：不是因为热爱写作。我其实不太爱写东西，比起写，我更喜欢动手做点什么。

真正把这件事推起来的，是两个原因。

**一是兴趣使然。** 就是想亲手做一个完全属于自己的网站。平台当然省事——公众号、知乎、小红书，随便一个都比从零搭建快，但那些地方终究是租来的：排版是平台的，流量是平台的，规则一变就得搬家。自己搭一个网站更像盖一间小房子：水电自己接，家具自己打。哪怕丑一点、偏一点，每一块砖都是自己的。

**二是 AI 发展了。** 以前，**从零搭一个完整的网站** 对我来说是个庞大到吓人的工程，前端、后端、登录、部署，每一块都是山。现在 AI 把很多门槛踩矮了一截，以前做不到的事，变成了踮踮脚就够得着的挑战。与其在旁边围观这场变化，不如跳进去亲手试一试。

于是，就有了这个站。

## 技术栈，以及一些非常诚实的原因

网上的技术选型文章，理由通常都很体面：**高性能**、**生态成熟**、**行业最佳实践**。这一篇不一样，我说实话——不是不想体面，是真没有：

| 技术 | 干什么 | 为什么选它 |
|---|---|---|
| React | 前端框架 | 纯粹好奇，想亲手用一次 |
| TypeScript | 类型系统 | 类型救过我很多次，不解释了 |
| Vite | 构建工具 | 快，快到不好意思说自己在等编译 |
| Emotion | 组件样式 | 样式写在组件里，跟着组件一起长大 |
| PHP | 后端 | 想从零开始学后端，它老实、朴素、没魔法 |
| Redis | 缓存 | 存验证码这类看一眼就该扔的临时数据 |
| JWT | 登录态 | 自己签发自己校验，把登录流程完整踩一遍 |
| GitHub OAuth | 第三方登录 | 那串来回跳转到底在跳什么，我想知道 |

**前端选 React，理由是好奇。** 声明式 UI、组件化、状态驱动——这些词到处都在说，但没自己用过，它们就永远只是词。索性拿它搭一个完整的站，比看十篇教程都管用。好奇心是学东西最老实的理由。

**后端选 PHP，理由更诚实：我想从零开始学后端。** 现在让 AI 一句话生成一整套 API 毫不费力，但我想要的是每一步都自己踩过：一个登录请求到底经历了什么，JWT 是怎么签出来又怎么验回去的，验证码邮件是怎么发出去的，GitHub 登录那一串来回跳转的 OAuth 到底在跳什么。

整个站的骨架，画出来大概是这个样子：

```text
浏览器
  │  React + TypeScript + Vite
  ▼
PHP 后端 ──┬── Redis（验证码 / 临时状态）
           ├── GitHub OAuth（第三方登录）
           └── JWT（登录态签发与校验）
```

## 这个站现在有什么

说实话，不多，但每一块都是自己搭的：

| 模块 | 现状 |
|---|---|
| 登录系统 | 访客模式什么都不用填，进来就算朋友，90 天免登录；想正式一点就邮箱验证码登录，或 GitHub 一键进门 |
| 头像系统 | 能上传自己的头像；GitHub 用户可一键同步 GitHub 头像，不用传两次 |
| 博客 | 就是你现在读的这个。文章是 Markdown 文件，没有数据库，写完放进目录就算发布 |
| 友链页 | 以后认识更多站长，互相串门用的 |
| 日历和目录卡片 | 博客页右边那两个小家伙 |

## 首页还很空，所以，愿望清单

现在的首页基本只有一句自我介绍，空得能跑马——马撒开蹄子跑都撞不着东西的那种空。正好，把以后想加的东西写在这里，立个字据：

- [ ] **首页充实计划**：光一句自我介绍实在太冷清，得让它热闹起来
- [ ] **天气小组件**：显示你——也就是访问者——所在地的天气，你那边在下雨，站里就飘一朵云
- [ ] **时间小组件**：现在几点、今天星期几，至少让访客确认这个站是活的
- [ ] **评论系统**：博客没有评论，就像开了店不让人说话。想自己写一套，正好给 PHP 后端当练习题
- [ ] **访问量统计**：想知道到底有没有人来过，以及来过的人有没有回头
- [ ] **项目页**：架子已经搭好了，等项目做出来往里填
- [x] ~~**关于页**：关于页面现在还是空的，这篇就先当它的临时替身~~
- [ ] **归档页**：页面已经在了，等文章多起来，把写过的东西按时间码整齐
- [ ] 没想好的，想到了再补

这份清单会跟着这个站慢慢变短。每勾掉一项，大概都会有一篇新的文章。
