## 先认识一下

大家好，我是 Fuhao574，这个网站的主人。前端、后端、测试、运维，还有没什么事可干的运营，暂时都由我兼着。毕竟刚开站，访客大概也就我自己和几只搜索引擎爬虫，暂时还不需要扩招哈哈哈。

站名叫 **这个世界不缺大人**，以后打开网页，标签上就会挂着它。具体为什么叫这个，我也不太会解释，就是觉得已经有那么多人在按部就班地生活了，自己留个地方，学点想学的东西，做点没那么实用的事，好像也挺好。

## 为什么 2026 年了还要自己搭网站

先说，不是因为我特别热爱写作。比起坐下来写一篇文章，我还是更喜欢动手改点东西，所以网站做出来了，不代表以后就能勤快更新，这个先别对我抱太大期待。

主要还是想要一个完全属于自己的地方。公众号、知乎、小红书当然方便，注册完就能用，但页面怎么排、什么能改，基本都是平台说了算。自己搭站就不一样了，喜欢什么放什么，今天想改颜色，明天想加个页面，哪怕最后不好看，也是我自己改丑的。

还有一个原因是现在有 AI 帮忙了。以前一想到前端、后端、登录和部署都得做，我可能看完教程就先关了。现在遇到不懂的地方能边问边试，至少敢把项目建起来了。当然不是一句话就全做完，改到一半发现哪里不对，该折腾还是得折腾，不过总比一直停在想做的阶段好。

![租来的平台 vs 自己盖的房子](https://img.fuhao574.cyou/images/hello-world/rent-vs-own.webp)

## 用了些什么，为什么选它们

技术栈先放在下面，别期待什么大型选型报告。我选这些东西，很多时候就是想用一下，或者想弄明白它怎么工作。个人站嘛，先拿来学，暂时也没有那么多流量等着我去优化。

| 技术 | 干什么 | 为什么选它 |
|---|---|---|
| React | 前端框架 | 纯粹好奇，想亲手用一次 |
| TypeScript | 类型系统 | 类型救过我很多次，不解释了 |
| Vite | 构建工具 | 启动和构建比较省事，不想一直等 |
| Emotion | 组件样式 | 样式跟组件放一起，找起来方便 |
| PHP | 后端 | 想从接口开始学后端，先用它试试 |
| Redis | 缓存 | 存验证码这类看一眼就该扔的临时数据 |
| JWT | 登录态 | 自己签发自己校验，把登录流程完整踩一遍 |
| GitHub OAuth | 第三方登录 | 那串来回跳转到底在跳什么，我想知道 |

前端选 React，纯粹是好奇。组件化、状态驱动这些词看了很多次，不自己做点东西还是没什么感觉，那就拿本站试试。按钮点了为什么没反应，状态变了页面怎么没更新，真遇到了，比只看概念记得牢。

后端用 PHP，也是想从登录这些具体功能开始学。AI 能帮我写，但我还是想知道请求发出去后发生了什么，验证码存在哪，JWT 怎么签，GitHub 登录来回跳转又是在忙什么。总不能登录能用了，我自己还完全不知道它怎么进来的吧。整个站大概是下面这个结构，先把这几块接起来再说。

## 这个站现在有什么

刚开站，东西还不多，先记一下这时候能用的功能。后面肯定会改，就当给第一版留张清单，免得过段时间连自己都忘了最开始长什么样。

| 模块 | 现状 |
|---|---|
| 登录系统 | 访客模式不需要真实账号，状态保留 90 天；Friend 账号通过 GitHub 创建，已有账号也能用邮箱验证码登录 |
| 头像系统 | 能上传自己的头像；GitHub 用户可一键同步 GitHub 头像，不用传两次 |
| 文章 | 就是你现在读的这个。当时正文是 Markdown 文件，不存数据库，构建后展示 |
| 友链页 | 以后认识更多站长，互相串门用的 |
| 日历和目录卡片 | 博客页右边那两个小家伙 |

## 首页还很空，所以，愿望清单

首页现在基本只有一句自我介绍，空是挺空的，不过至少上线了。先把想加的东西记下来，后面有空慢慢填。这是开站时的想法，不保证每项都会做，做到一半觉得不需要了，也可能直接删掉。

- [ ] **首页充实计划**：光一句自我介绍实在太冷清，得让它热闹起来
- [ ] **天气小组件**：显示你——也就是访问者——所在地的天气，你那边在下雨，站里就飘一朵云
- [ ] **时间小组件**：现在几点、今天星期几，至少让访客确认这个站是活的
- [ ] **评论系统**：博客没有评论，就像开了店不让人说话。想自己写一套，正好给 PHP 后端当练习题
- [ ] **访问量统计**：想知道到底有没有人来过，以及来过的人有没有回头
- [ ] **项目页**：架子已经搭好了，等项目做出来往里填
- [x] ~~**关于页**：关于页面现在还是空的，这篇就先当它的临时替身~~
- [ ] **归档页**：页面已经在了，等文章多起来，把写过的东西按时间码整齐
- [ ] 没想好的，想到了再补

希望以后能把这份清单慢慢填上，顺便写点过程。不过按我喜欢改东西、不太喜欢写东西的习惯，功能可能会先长出来，文章晚点再补，先提前交代一下。

## 最后

按写代码的习惯，第一句话应该是 Hello, World，那就在这里跟大家打个招呼吧。网站还很简陋，有空可以来逛逛，看看我又加了什么，或者又把什么改坏了。欢迎路过的大人和小孩，慢慢玩。
