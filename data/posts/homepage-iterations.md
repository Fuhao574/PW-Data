关于页上线那篇的结尾，我写过一句 **三次推翻重来**。那是写自我介绍，三天。

首页呢？四十六份稿子。

对，四十六。我自己数完第一遍也不太信，又数了一遍。

打开 `archive/drafts-2026-09/` 那个文件夹，四十六个 HTML 和 MD 躺成一排，从 v1 蓝图排到 v10 探索，中间还夹着三个备胎和五个方向。每个文件的名字都是一次心跳：`主页设计蓝图 v3 · 导航站 + 小工具站`、`首页稿-B-终端式`、`汽泡 FIZZ · 全站设计语言 V2`、`设计稿 B · 暗房接触印样`。光看文件名，能看出我那阵子每天在想什么。

今天这版上线了。但先说清楚一件事：**它不是最终版**。

## 为什么首页最难

博客写给读者，代码写给机器，关于页写给陌生人。首页写给谁？写给我自己。

它是 **你想成为什么样的人** 这个问题的可视化。所以它难，难到每次打开设计稿，都像在重新回答一遍这个问题。写代码有编译器告诉你哪里错了，设计没有，只有心里那句 **不对，还不是这个感觉**。

四十六份稿子，就是这句话说了四十六遍。说的人是我，听的人也是我，全程一个人开会。

## 手账风：一场美丽的误会

最开始，我想要的是手账风。贴纸、便利贴、吊牌、日期章、取景框角标——站点本来就说这套话，首页是把它说到位的地方。

蓝图 v1 叫 **翻开的台面**：把首页当作一本翻开的手账，访客从扉页开始，往下滚等于往里翻——扉页立人设，中间摊开台面，末页挂留言板的吊牌。证件照贴纸旋转 -2° 配硬投影，标题用龙藏手写体，配一行印章式的数据条。蓝图写得很好，稿子也很好看。

然后我把它否了。

否的理由很具体：**手写体影响阅读**。好看是好看，可首页是要被读的，满屏手写体读两行就累。而且手账风和博客、友链这些页放在一起，像客厅里摆了张书桌——温馨，但格格不入。

> 首页不要手账风了，和其他页面真是格格不入。

手写体、贴纸、撕纸动画、现在时钟，全删。`Home.tsx` 从 2310 行砍到 1114 行，四十一个手账组件跟着陪葬。删得最彻底的是字体：`theme.fonts.hand` 这个手写轨道整个从主题里拿掉了，`main.tsx` 里的龙藏导入也删了——手写体在这站里正式失业。

## 五个方向，和三个备胎

手账风倒了，接下来是连环推翻。

**三个备胎**：报刊编辑式（A）、终端状态板（B）、卡片杂志式（C）。A 用衬线大字学报纸头版，B 学终端窗口全是等宽字，C 学杂志网格错落排布。做了，都不对——都只是 **别人的衣服**，不是我的。

**五个方向**：墨线 Inkline、汽泡 FIZZ、玻璃手账、书桌俯瞰、暗房接触印样。名字一个比一个唬人，稿子一份比一份精致，感觉一份比一份不对。

有两个值得点名。墨线 Inkline 是工程图纸风，淡墨线、图例、施工标注，做完整套设计语言才发现问题——我在自己的评审记录里写的是：**工程图纸太成熟稳重**。一个叫 **这个世界不缺大人** 的站，首页长得像市政施工图，不太对劲。汽泡 FIZZ 反着来，大圆角、发光软影、弹簧回弹、贴纸荧光笔，全都指向 **年轻**——这回又太用力了，克制没跟上。

中间还参考过一个很喜欢的站，照着人家的骨架重排过一次。结果和关于页第二版一个毛病：**借来了骨头，没借来气**。人家的敞亮是长在人家的性格上的，我搬回来的是户型图，不是房子。

## 最后留下的那一版

推翻到第三十几次的时候，我不再问 **想要什么风格** 了，改问一个问题：

**首页最不能少的是什么？**

答案是两样。一个是**我的头像**——这是一个人的站，进门得见人。一个是**不突兀**——它可以特别，但不能和其它页面像两个站。

于是有了现在这版。顶部一条刊首：创刊日期、天气、脚印数、最近更新——四个全是活读数，天气定位到访客的城市，拿不到就显示 **抬头看天**。刊首下面是全站唯一的渐变面板，左边是站名大字和两个入口按钮，右边是毛玻璃个人卡，文章、字数、友邻、脚印四格数字。巨大的幽灵字 **2026** 压在背景里，等宽体，像刊号。再往下，头条卡和留言吊牌全部回归站点的卡片语言，不多发明一个新词。

它不是任何一种 **风**。它就是**这个站的样子**：有刊首的仪式感，有个人卡的存在感，其它的留白。

## 为什么不是最终版

这版能上线，是因为它**先够用了**。但 **够用** 和 **定稿** 之间，差着一个待办清单：

- 天气小组件的数据源还想再稳一点
- 渐变面板的幽灵字在窄屏上会挡内容，得调
- 分区之间的节奏，还想再松一点

**为什么不趁热打到底？** 因为首页是最后一道工序。文章系统、留言板、登录、个人中心——这些功能还在长，首页得等功能齐了再收口。现在就把首页钉死，等于给一栋还在加层的房子先装大门，量好了尺寸，回头墙又挪了。

所以这版的定位很明确：**过渡版，先用着**。等我哪天觉得功能齐了，再回头收口。到时候它大概也会变成第四十七份稿子，躺进 archive 文件夹里。

## 字体：顺手做的瘦身

改首页的时候顺手称了次重，被吓一跳：构建产物里 **1260 个字体文件，33MB**。一个以文字为主的站，字体比文章还重，说出去都嫌丢人。

来源是 `@fontsource`——每个字重一份 CSS，每份 CSS 又引用西里尔、希腊、越南语等十几个子集的字体文件。我的站是中文和英文，这些子集**永远不会被请求**，但它们全被拷进了构建产物。

处理办法是给 Vite 写了个字体瘦身插件，在 `generateBundle` 钩子里动手：

```ts
// vite.config.ts · fontTrimPlugin（节选）
const DEAD = /-(?:cyrillic|cyrillic-ext|greek|greek-ext|vietnamese)-/;

// 命中的 woff2 与 legacy .woff 直接从产物里删掉
if (/\.woff$/.test(fileName) || DEAD.test(fileName)) {
  delete bundle[fileName];
}
// CSS 里对应的 @font-face 声明也要同步抠掉，
// 不然字体文件没了、声明还在，浏览器会对着 404 干瞪眼
```

效果很明显：

| | 改之前 | 改之后 |
|---|---|---|
| 字体文件 | 1260 个 | 588 个 |
| 总体积 | 33MB | 15MB |

剩下的 588 个里，564 个是中文 Noto Sans SC 按 Unicode 切的块。这个**不是浪费**——`unicode-range` 机制下，浏览器只会下载页面上用到的字所在的那几块，等于按需加载。中文全量字体一个就 1.1MB，比分块加载还重。

顺带一提，为什么不直接用 CDN 的 Google Fonts：**国内访问不稳**，首屏可能卡到字体一直不渲染。自托管走 Vercel 边缘节点反而更快。方向是对的，只是之前没做裁剪。

## 一些感悟

**推翻是常态，不是失败。** 四十六份稿子看着吓人，但没有它们，我大概会在第三版就凑合定稿，然后每天打开站点都觉得**哪里不对**。推翻是付学费，付够了，答案自己浮出来。

**想要什么风格，是错的问题。** 正确的问题是**什么不能少**。风格可以抄，不能少的东西抄不来。

**先够用，再完美。** 这版首页上线的时候，我心里清清楚楚它有几处毛病。但完美主义的代价是永远不上线，而上线的好处是**它开始自己长**——刊首的文章数、脚印数，每天都在动。

至于第四十七份稿子什么时候动手——等功能齐了再说。

> 先让站跑起来，再让它好看。顺序反了，两头都落空。
