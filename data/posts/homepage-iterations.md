之前写关于页，说推翻了三次才上线，我以为已经够能改了。结果轮到首页，打开归档文件夹一数，四十六份稿子。数完还不太信，又看了一遍，确实是四十六份，我真服了。

`archive/drafts-2026-09/` 里面 HTML 和 MD 排了一堆，从 v1 蓝图到 v10 探索，中间还有备选方向。什么导航站、终端式、汽泡 FIZZ、暗房接触印样，光看文件名都能看出我有多摇摆。总之现在这版终于上线了，先用着，别问是不是最终版，我不敢保证。

## 为什么首页最难

首页跟其他页面还不太一样。文章页能读，留言板能发，这些至少有个明确的目标，首页却很难说做到哪里就算好了。想有点个人风格，又不想太花；想放东西，又嫌挤；真的留白了，又觉得空，自己都快被自己烦到了。

代码写错了还有报错，设计不喜欢就是不喜欢，也说不出一个能立刻改好的理由。很多稿子单独看其实不错，放进本站就觉得不对，然后继续换。四十六份不是四十六次进步，里面不少就是绕了一圈又回来。

## 手账风挺好，但先不要了

最开始想做手账风，贴纸、便利贴、吊牌、日期章这些都往上放。第一版蓝图叫翻开的台面，往下滚就像翻手账，前面介绍自己，中间放内容，最后挂留言板的吊牌。头像还要斜着贴，配硬阴影，标题用龙藏手写体，细节是挺齐全的。

看稿时觉得好看，真要每天打开读，又觉得手写体太多了。装饰和文字都在抢注意力，跟文章页、友链页放一起也不像同一个站。那就别硬留了，手写体、贴纸、撕纸动画，还有那版时钟，一起拿掉。

`Home.tsx` 从 2310 行变成 1114 行，四十一个手账组件也删了。字体更彻底，`theme.fonts.hand` 和 `main.tsx` 里的龙藏导入一起移除。做的时候一块块加进去，删的时候倒是挺快，有点心疼，但看着不对也没办法。

## 五个方向，和三个备胎

接下来又试了报刊编辑式、终端状态板、卡片杂志式三个备选。报刊版用衬线大字，终端版全是等宽字，杂志版排错落网格，各有各的好看，但还是没挑出来。后面继续试墨线 Inkline、汽泡 FIZZ、玻璃手账、书桌俯瞰、暗房接触印样，名字听着一个比一个厉害，打开之后我还是能找出不喜欢的地方。

墨线是淡墨线、图例、施工标注那种工程图纸风，做完觉得太成熟稳重了。站名叫这个世界不缺大人，首页看着倒挺像来办正事的。汽泡 FIZZ 又往另一边走，大圆角、软阴影、弹簧回弹，活泼是活泼，但太用力了，看久了还是想减东西。

中间也照着一个喜欢的站重新排过，跟改关于页时差不多，人家的结构搬过来，换上我的内容就没有那个感觉了。参考还是有用的，至少知道自己喜欢什么，但要做成自己的页面，光照着排还不够。

## 最后留下的那一版

试到后面，不想再选一堆风格名了，先确定必须留下什么。头像要有，个人站进来总得看见主人；其他部分别跟站内页面差太远，不然每切一次页都像重新进了一个网站。

现在这版顶部放了创刊日期、天气、脚印数和最近更新，天气按访问者城市取，拿不到就显示抬头看天。下面是渐变面板，左边站名和入口，右边毛玻璃个人卡，放文章、字数、友邻、脚印四格数据。背景里的 2026 留着，下面的头条卡和留言吊牌还是用站里的卡片样式。

没有再给它起一个新的风格名，就先这样吧。至少首页有自己的样子，往其他页面走也不突兀，不用为了特别，再把每个组件重新发明一遍。

## 为什么不是最终版

能上线不是因为完全没问题了，而是已经能用了。还有几处当时就想接着调，先记在下面，免得改完别的又忘了首页还欠着这些。

- 天气小组件的数据源还想再稳一点
- 渐变面板的幽灵字在窄屏上会挡内容，得调
- 分区之间的节奏，还想再松一点

文章、留言板、登录和个人中心还在改，首页上的入口也可能跟着变，现在把布局定死，后面说不定又要拆。先用这版，其他功能慢慢补，等哪天真想明白了再回来改。至于那时候会不会多出第四十七份稿子，我觉得很有可能。

## 字体：顺手做的瘦身

改首页时还发现，构建产物里有 **1260 个字体文件，33MB**。文章都没几篇，字体先攒这么多。查了一下是 `@fontsource` 引入的字重和子集，西里尔、希腊、越南语这些也都打包了，本站主要写中文和英文，留这么齐全干什么。

后来给 Vite 加了字体裁剪插件，在 `generateBundle` 里删掉不用的子集和旧版 `.woff`，CSS 中对应的 `@font-face` 也一起移除。只删文件不改声明，后面浏览器真用到的时候就会请求 404，不能光看文件夹变小就算改好了。

```ts
// vite.config.ts · fontTrimPlugin（节选）
const DEAD = /-(?:cyrillic|cyrillic-ext|greek|greek-ext|vietnamese)-/;

// 命中的 woff2 与 legacy .woff 直接从产物里删掉
if (/\.woff$/.test(fileName) || DEAD.test(fileName)) {
  delete bundle[fileName];
}
// CSS 里对应的 @font-face 声明也要同步抠掉，
// 不然字体文件没了、声明还在，浏览器会对着 404 干瞪眼
```

这一轮裁剪前后如下。这里说的是构建产物大小，不是访客打开一次页面就会下载这么多，别看见 33MB 就以为进站先收一大包字体。

| | 改之前 | 改之后 |
|---|---|---|
| 字体文件 | 1260 个 | 588 个 |
| 总体积 | 33MB | 15MB |

剩下 588 个里有 564 个是 Noto Sans SC 的中文分块，这些不是看到文件多就该删。`unicode-range` 会让浏览器按页面用到的字下载对应块，不是每次全取一遍。原来那份中文全量文件约 1.1MB，具体下载多少还是得看页面和字重，不能只比文件数量。

没直接换成 Google Fonts CDN，主要还是担心国内访问不稳定，先继续自托管。裁剪完至少把明显用不上的东西拿掉了，后面真要比较加载快慢，还得看网络请求，不能只凭产物体积下结论。

## 先别问下一版什么时候改

四十六份稿子折腾下来，也没悟出什么设计秘诀，倒是更清楚自己不喜欢什么了。有些稿子确实好看，但我不想每天打开都看见它，硬留着也没意思。现在这版能用，看着也没那么想立刻推翻，那就先上线。

下一版等其他功能做完再说吧，至少写这篇的时候我是这么想的。希望别刚说完，又打开归档文件夹开始做第四十七份了。
