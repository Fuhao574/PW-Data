# 构建输入与产物安全

## 范围

所有逻辑/测试 `.mjs` 放在 `scripts/`，不进入主站浏览器。构建需要开发依赖（`npm ci --include=dev`）；新增 `ipaddr.js` 做地址分类，无 Node 版本要求提升。
`npm run build` 先运行离线测试，再生成产物。测试需本机 openssl CLI（本机 TLS fixture），不访问线上 Redis/API/友站。

## 契约

- 友链源必须是对象，name/description/URL 字段为字符串；name 最长 60、description 最长 200，URL 最长 2048。可选 avatar/rss/backlink 允许缺失或空字符串，不接受错误类型/null。
- HTTPS 默认 443，不带账号密码。拒绝静态私网 IP/localhost 等明显非法目标。名称与规范化站点 URL 不能重复，源不能填写构建生成的 accent/order/snippet。
- 头像与旧快照下载逐跳校验全部 DNS 答案，并绑定已检查 IP；最多三跳，禁止转 HTTP/内网。TLS 保持证书校验，不使用环境变量代理。
- 头像最大 8 MiB，格式限 PNG/JPEG/WebP/GIF/AVIF，MIME 允许相应 image 类型和 octet-stream（仍须通过 sharp 格式检查）。最大 16,777,216 累计像素、300 帧。超限/网络失败沿用有效旧 accent/快照；没有旧值时保持原有默认色/兜底，不阻断其他内容。
- 原始头像字节不重编码，Alpha 和动画保留。16×16 主色采样仍使用原图第一帧，不改变原有取色算法。
- slug 允许大小写字母、数字和连字符，最长 120，禁止路径分隔符/点路径；大小写冲突拒绝。不改 `how-to-choose-SHP` 或其他已有文章 URL。
- 发布文章必须有合法的时间字符串（保留现有无时区时间格式），draft 必须是真布尔值；tags 为最多 30 项字符串数组。标题缺失仍以 slug 兜底，其他现有可选字段缺省保持。
- 每篇已发布 HTML 最多 4 MiB；元数据新增 `htmlSha256`，对生成 HTML 的 UTF-8 字节计算 SHA-256。哈希只检测同步版本一致性，不是签名，不防止被同时篡改的元数据与正文。
- 草稿保留元数据，不输出公开 HTML。

## 暂存/恢复

新产物先写仓库根 `.build-transaction/stage/dist`，全部成功后切换 `dist`。失败保留旧 `dist`。
`.build-transaction` 内日志和旧备份用于中断恢复，下次构建在开始前处理。锁阻止两个构建同时改同一目录。
不是多文件系统 ACID，也不保证机器断电后的 fsync 持久性；支持正常异常回滚和进程退出后的下次恢复。切换 `dist` 存在短暂 rename 间隙，不能作为实时服务热更新方案。
事务目录被 Git 忽略，构建成功后清理。PID 锁缺失/异常或损坏日志时停止，不自动猜测并删除；手动确认无运行进程、保留备份后再排查。
不要在恢复前手动删除事务目录，否则可能丢失旧产物备份。

## 上线顺序与成本

1. 先部署本数据仓库，确认 `data/posts.json` 的公开文章有 `htmlSha256`。
2. 再部署主站的新同步脚本，构建时验证正文哈希后切换。
3. 旧主站忽略新增哈希字段，兼容新数据；新主站拒绝缺少哈希的旧数据，失败阻止发布且保留旧本地产物。

单条非法结构会阻断整个构建；资源限制可能拒绝原先能下载的超大/特殊头像。暂存+旧备份需要约两份产物磁盘空间，DNS/安全检查与测试增加构建耗时。
旧产物不可用时友链仍按原有头像兜底规则工作；不做浏览器 Markdown 解析或前端样式改动。

```sh
npm test
npm run build
```
